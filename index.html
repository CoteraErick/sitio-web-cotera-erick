Presentación

Bienvenidos a mi sitio web desarrollado para la practica de laboratorio.

El propósito de este laboratorio es aplicar conocimientos básicos de HTML y aprender a gestionar versiones mediante Git y GitHub.

Contenido del sitio

En este sitio encontrarás información personal, intereses académicos y diferentes pasatiempos.

Objetivos de la practica

  1. Desarrollar páginas web utilizando HTML.
  2. Implementar navegación entre páginas.
  3. Administrar versiones con Git.
  4. Publicar cambios en GitHub.
