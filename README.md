# Sitio Web Personal

## Descripción del proyecto
Sitio web desarrollado como parte de la Práctica N.º 2 de la asignatura Fundamentos de Sistemas Web, denominada **Versionamiento de Aplicaciones**.

La practica permite aplicar conocimientos básicos de HTML y utilizar Git y GitHub para registrar modificaciones, organizar ramas y controlar las diferentes versiones del sitio web.

## Objetivo
Aplicar técnicas de versionamiento de aplicaciones mediante Git y GitHub, gestionando las modificaciones del código fuente desde el desarrollo hasta la versión final.

- HTML

## Funcionalidades implementadas
- Página principal con menú de navegación.
- Página de información personal.
- Página de pasatiempos con listas y tablas.
- Incorporación de imágenes y videos.
- Navegación entre las páginas HTML.

## Estructura del proyecto

```text
sitio-web-pareja/
├── index.html
├── sobre-nosotros.html
├── pasatiempos.html
├── imagen/
├── video/
└── README.md
```

## Ramas utilizadas
- `main`: versión final del proyecto.
- `desarrollo`: integración de funcionalidades.
- `pruebas`: validación del funcionamiento.
- `feature-erick-inicio`: desarrollo de la página principal.
- `feature-erick-contenido`: desarrollo de páginas secundarias y recursos multimedia.
- `feature-erick-documentacion`: documentación del proyecto.

## Instrucciones de ejecución
1. Descargar o clonar el repositorio desde GitHub.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador web.
4. Utilizar el menú de navegación para acceder a las páginas.

## Comandos Git utilizados
- `git init`: inicializar un repositorio.
- `git add`: preparar modificaciones.
- `git commit`: registrar cambios.
- `git branch`: consultar ramas.
- `git switch`: cambiar de rama.
- `git merge`: fusionar ramas.
- `git push`: publicar cambios.
- `git pull`: actualizar el repositorio local.
- `git log`: consultar el historial de versiones.
- `git status`: comprobar el estado del repositorio.
